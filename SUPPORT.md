# LeakLens Support 💡

We want to make sure you have the best experience using LeakLens. Here is how you can get help or
stay updated.

## ❓ Have a Question?

If you're unsure how to use a feature or have a general question about memory leaks:

* **GitHub Discussions
  **: [Start a discussion](https://github.com/dev-vikas-soni/leak-lens/discussions) on our
  repository. This is the best place for community Q&A.
* **Documentation**: Check the [User Manual](docs/USER_MANUAL.md)
  or [Architectural Overview](docs/ARCHITECTURAL_OVERVIEW.md).

## 🐞 Found a Bug?

If LeakLens isn't working as expected:

1. Check the [Issue Tracker](https://github.com/dev-vikas-soni/leak-lens/issues) to see if it has
   already been reported.
2. If not, [open a new issue](https://github.com/dev-vikas-soni/leak-lens/issues/new) using our bug
   report template.
3. Please include your IDE version, OS, and (if possible) the leak trace or `.hprof` file.

## ✨ Feature Requests

Have an idea to make LeakLens better?

* Please use the **Feature Request** template
  on [GitHub Issues](https://github.com/dev-vikas-soni/leak-lens/issues/new).
* Tell us why the feature is needed and how it would improve your workflow.

## 🛡️ Security Vulnerabilities

Please do **not** report security vulnerabilities via public issues. Refer to
our [Security Policy](SECURITY.md) for instructions on how to report them privately.

## 💼 Commercial Support

LeakLens is a community-driven open-source project. Currently, we do not offer formal commercial
support contracts. If you are an enterprise interested in custom rules or integration, please
contact **vikasacsoni9211@gmail.com**.
