Reports anonymous classes (Java) and object expressions (Kotlin) created inside an Activity or Fragment and handed to something that can outlive it:
  • a Thread (subclass or constructor argument);
  • Handler.postDelayed/postAtTime/sendMessageDelayed/sendMessageAtTime;
  • Executor.execute/submit/schedule* and Timer.schedule*;
  • a static field.

Java anonymous classes always hold a reference to the enclosing instance. Kotlin object expressions are only reported when they actually capture the outer class.

Leaks:


handler.postDelayed(new Runnable() {
    @Override public void run() { updateUi(); }
}, 60_000);

Fix: use a static nested class (holding a WeakReference if it needs the Activity), or cancel the work in onDestroy().
