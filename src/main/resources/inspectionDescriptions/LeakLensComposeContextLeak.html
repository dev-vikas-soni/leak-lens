Reports a UI Context (for example LocalContext.current), Activity or View passed from Compose code into a ViewModel or ViewModelProvider.Factory that stores it.

The ViewModel outlives the composition and the hosting Activity, so the stored Context leaks after a configuration change.

Leaks:


@Composable
fun Screen(vm: SettingsViewModel) {
    vm.bind(LocalContext.current) // SettingsViewModel keeps it in a field
}

Fix: pass LocalContext.current.applicationContext (quick fix), or keep Context-dependent work in the UI layer. Calls whose parameter is only used transiently are not reported.
