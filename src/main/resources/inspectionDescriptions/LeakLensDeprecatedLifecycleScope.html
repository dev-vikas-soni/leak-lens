Reports lifecycleScope.launchWhenCreated/Started/Resumed.

These APIs are deprecated: they suspend the coroutine while the lifecycle is below the target state instead of cancelling it, so upstream flows, callbacks and the resources they hold stay alive in the background.

Before:


viewLifecycleOwner.lifecycleScope.launchWhenStarted {
    viewModel.state.collect { render(it) }
}

After (available as a quick fix):


viewLifecycleOwner.lifecycleScope.launch {
    viewLifecycleOwner.repeatOnLifecycle(Lifecycle.State.STARTED) {
        viewModel.state.collect { render(it) }
    }
}
