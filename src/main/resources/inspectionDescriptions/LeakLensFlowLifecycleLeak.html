Reports Flow collection in Activities, Fragments and Compose that keeps running while the UI is in the background:
  • collect/collectLatest inside lifecycleScope.launch { } without repeatOnLifecycle or flowWithLifecycle;
  • flow.launchIn(lifecycleScope) without flowWithLifecycle;
  • collectAsState() in a @Composable (weak warning).

Leaks:


lifecycleScope.launch { viewModel.state.collect { render(it) } }

Safe:


lifecycleScope.launch {
    repeatOnLifecycle(Lifecycle.State.STARTED) { viewModel.state.collect { render(it) } }
}

val state by viewModel.state.collectAsStateWithLifecycle()

Quick fixes wrap the collection in repeatOnLifecycle, insert flowWithLifecycle, or switch to collectAsStateWithLifecycle().
