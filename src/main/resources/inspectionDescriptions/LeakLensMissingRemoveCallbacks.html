Detects Handler usage where removeCallbacksAndMessages(null) is not called in a teardown callback (onDestroy(), onDestroyView(), onStop(), onDetachedFromWindow(), ...) for Handlers that schedule delayed work in an Activity, Fragment or View.

Pending messages in a Handler hold a reference to the handler, which in turn often holds a reference to the Activity. Failing to clear these messages can lead to memory leaks.

Fix: Call handler.removeCallbacksAndMessages(null) in onDestroy() (Activity), onDestroyView() (Fragment) or onDetachedFromWindow() (View). A quick fix inserts the call.
