Reports static fields (Java static, Kotlin companion object / object properties) whose type is bound to a UI lifecycle: Activity, Fragment, View, Dialog or a non-Application Context.

Static fields live as long as the process. Holding a UI object there keeps the destroyed Activity and its whole view hierarchy reachable.

Leaks:


class MainActivity : Activity() {
    companion object {
        var current: MainActivity? = null
    }
}

Fix: pass the object where it is needed, use applicationContext for app-wide needs, or clear the field in onDestroy(). Fields annotated with Hilt's @ApplicationContext and Application-typed fields are not reported.

Suppress with @Suppress("LeakLensStaticActivityReference").
