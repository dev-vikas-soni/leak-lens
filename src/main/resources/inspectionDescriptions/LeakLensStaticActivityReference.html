Detects cases where an Activity or Fragment is stored in a static field or a companion object.

Storing an Activity or Fragment in a static field causes a memory leak because static fields persist for the lifetime of the application process, preventing the Activity or Fragment from being garbage collected after it is destroyed.

Example:


class MyActivity : Activity() {
  companion object {
    var staticActivity: MyActivity? = null // Leak!
  }
}

Fix: Use a WeakReference or clear the static reference in onDestroy().
