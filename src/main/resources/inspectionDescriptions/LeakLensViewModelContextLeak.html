Reports ViewModel (including AndroidViewModel) fields that hold an Activity, Fragment, View, Dialog, Drawable or a non-application Context.

ViewModels survive configuration changes, so any UI object they keep outlives the Activity that created it.

Leaks:


class ProfileViewModel(private val activity: Activity) : ViewModel()

Safe:


@HiltViewModel
class ProfileViewModel @Inject constructor(
    @ApplicationContext private val context: Context
) : ViewModel()

Context fields are not reported when they come from @ApplicationContext, applicationContext or getApplication().
