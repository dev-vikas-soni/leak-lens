Reports WorkManager workers (ListenableWorker subclasses) that store a Context in a field.

Workers already expose applicationContext. Keeping the constructor Context in a field is redundant and becomes a leak when a custom WorkerFactory passes a non-Application Context.

Before:


class SyncWorker(private val ctx: Context, params: WorkerParameters) : Worker(ctx, params) {
    override fun doWork(): Result { use(ctx); return Result.success() }
}

After (available as a quick fix):


class SyncWorker(ctx: Context, params: WorkerParameters) : Worker(ctx, params) {
    override fun doWork(): Result { use(applicationContext); return Result.success() }
}
